# NEXORA AI — سجل التنفيذ والحالة الفعلية للمشروع

## المراحل المنجزة
- **المرحلة 1 (البنية والخادم):** إعداد Express + Vite + TypeScript، وتحديث `metadata.json` و`index.html` و`package.json`.
- **المرحلة 2 (قاعدة البيانات):** إنشاء قاعدة بيانات SQLite دائمة (`server/db/database.ts`) مع فهرسة FTS5، ومفاتيح منع التكرار `dedup_key`، وسجلات التدقيق، والنسخ الاحتياطي، وجداول المحادثات والدفعات.
- **المرحلة 3 و5 (الأقسام الخمسة ومحرك الاسترجاع):** بناء `server/knowledge/repository.ts` لدعم الاسترجاع من قسم أو أكثر، مع عدادات SQLite حقيقية لكل قسم.
- **المرحلة 4 و8 (NEXORA MASTER والأساليب السبعة):** بناء العقل الرئيسي الموحد (`server/brain/nexoraMaster.ts`) مع أساليب الرد السبعة، واكتشاف التناقضات، وحماية التوجيه الطبي التثقيفي.
- **المرحلة 6 (نظام الدفعات والاستكمال التلقائي):** بناء `server/knowledge/batchHarvester.ts` مع استيراد دفعي موثق من واجهات Wikipedia (EN & AR) وحفظ نقاط الاستكمال في جدول `batch_jobs`، وبذر 25 سجلًا تأسيسيًا موثقًا (5 لكل قسم).
  - **ملاحظة شفافة حول السجلات:** يحتوي النظام حاليًا على السجلات التأسيسية الموثقة بالإضافة إلى أي دفعات تم تشغيلها، والعداد الفعلي يعرض العدد الحقيقي المخزن من أصل الهدف `20,000` (`4,000` لكل قسم).
- **المرحلة 7 (محرك البحث الخارجي):** بناء `server/search/externalSearch.ts` باستخدام Gemini Google Search Grounding + Wikipedia API + OpenAlex API مع فحص التواريخ وترتيب الموثوقية وحماية SSRF.
- **المرحلة 9 (نظام الصوت):** بناء `src/services/voiceService.ts` + نقاط الخادم `/api/voice/transcribe` و`/api/voice/tts` مع دعم العربية والإنجليزية، وإدارة الأذونات، والانتقال بين الخلفية والمقدمة، وجسر Kotlin لنظام Android.
- **المرحلة 10 (التحكم وفتح التطبيقات):** بناء `src/services/deviceControlService.ts` + `src/shared/supportedApps.ts` + الجسرين `bridges/android/NexoraBridge.kt` و`bridges/windows-agent/nexora-bridge.mjs` مع تأكيد المستخدم قبل التنفيذ.
- **المرحلة 11 (واجهة المستخدم بدون توليد صور):** بناء واجهة متكاملة تدعم العربية RTL والإنجليزية LTR والمظهر النهاري/الليلي دون أي أدوات أو أزرار لتوليد الصور.
- **المرحلة 12 (ترقية الخصوصية والإدارة والأدوات والصوت والتحكم المباشر):**
  - **إخفاء قاعدة المعرفة:** حجب سجلات قاعدة المعرفة والأقسام الخمسة وسجلات النظام عن واجهة المحادثة العادية وحصرها في لوحة إدارة محمية بكلمة مرور (`scrypt` + توكن HMAC بالذاكرة).
  - **نظام الأدوات القابل للتوسع:** تفعيل `server/tools/registry.ts` (الرياضيات الآمنة، تحليل الملفات المرفقة، منظم المهام `user_tasks`، الذاكرة المشروطة بالموافقة `user_preferences`، البرمجة وتطوير الألعاب والترجمة والمقارنات).
  - **الإصلاح الجذري للميكروفون والصوت:** قياس مستوى الصوت الحقيقي عبر `AnalyserNode`، حالات التسجيل الثماني الصريحة، تثبيت النتائج المؤقتة عند الإيقاف، الاحتياطي التلقائي عبر `MediaRecorder -> /api/voice/transcribe`، وتفعيل Wake Word وإعدادات الصوت واختبار الميكروفون والسماعات.
  - **قواعد إيقاف القراءة الصوتية السبع:** إيقاف فوري عند انتهاء النص، أو زر الإيقاف، أو مغادرة المحادثة، أو تبديلها، أو بدء قراءة جديدة، مع احترام وضع الخلفية ومنع التكرار التلقائي.
  - **الفتح المباشر للتطبيقات:** تنفيذ فوري للتطبيقات غير الحساسة مع الإبقاء على التأكيد للأوامر الحساسة فقط.
